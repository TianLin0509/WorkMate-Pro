# 自动翻页截图工具

这是一个 Windows 桌面工具：先框住网页正文，它会自动试滚、识别相邻画面的真实重叠区域，只保留新出现的内容，再切成多张接近一屏高度的独立图片。网页不需要能复制，也不会先生成一张占用大量内存的超长图。

## 最快使用方式

1. 打开 `output\AutoPageCapture.exe`。
2. 在浏览器中把文档停在开头，回到工具点击“框选网页正文”。
3. 按住鼠标左键拖动，只框住希望截图的正文区域。
4. 保持“智能对齐（推荐）”，选择保存位置，点击“开始自动截图”。
5. 工具窗口会最小化。截图过程中不要操作鼠标；需要提前结束时按 `F8`。
6. 完成后会自动打开本次运行的独立文件夹。

每次运行都会新建目录，旧截图不会被覆盖：

```text
网页截图_20260809_164545\
├── page_001.png
├── page_002.png
├── page_003.png
└── capture_info.json
```

`capture_info.json` 是 UTF-8 运行记录，包含每次实际推进距离、重叠比例、置信度、是否使用保守估计以及结束原因。发送给 Agent 时通常只选择 `page_*.png`。

## 两种对齐模式

### 智能对齐（默认）

工具先发送一格滚轮并测出当前网页“一格实际移动多少像素”，随后闭环调整每轮滚动量。相邻截图会经过灰度、边缘和运动预测联合匹配，并在原始像素高度上二次精对齐。

智能模式会把实际推进维持在约 `@0.58～@0.86`：画面容易匹配时提高推进量，特征不足时主动增加重叠。这里的 `@0.80` 表示向前推进约一个视口高度的 80%，并不是固定滚轮格数。

### 固定比例

选中“固定比例”后可以填写 `@0.30～@0.90`。例如 `@0.75` 表示每轮目标推进 75% 视口、预留约 25% 视觉重叠。这个模式适合先对某类网页试验，再复用一个稳定值。

固定比例只固定“目标距离”；工具仍会先测量滚轮响应、逐轮视觉核对、去掉真实重复区域，并处理到达页面底部时不足一个目标距离的尾段。因此它比“固定滚 7 格”更不依赖窗口尺寸和网页滚动设置。

## 为什么不会又重叠又漏内容

手机滚动截图通常有两类实现：应用/系统直接提供可滚动内容，或者连续截图后用视觉特征寻找重叠并拼接。本工具采用后一类思路，但输出方式不同：

1. 保留当前画面作为锚点，并小步试滚校准。
2. 匹配旧画面下部与新画面上部；周期性列表同时用滚动预测约束，避免错配到相邻卡片。
3. 在原始垂直像素网格上精确求出位移，只追加新画面的未见尾部。
4. 内存里只保留约一到两屏的滚动缓冲；接近一屏时在低纹理横线附近切页。
5. 到底时确认画面连续不再变化，不重复保存末页。

所以内部逻辑类似“边滚边拼”，但不会形成一张超长图片；输出仍是方便单独查看和交给 Agent 的分页图片。

## 设置建议

- 默认先用智能对齐。只有需要严格复现某个推进比例时才用固定比例。
- “滚动后等待”默认 0.8 秒。页面含懒加载图片时建议改为 1.5～2 秒。
- 框选区域尽量只包含滚动正文。固定导航栏、悬浮按钮、视频、闪动广告和持续变化的水印会降低对齐置信度。
- 如果智能对齐无法得到可信结果，工具会停止并保留已经生成的图片，不会静默假装成功。少数纹理不足的画面会使用明确记录在清单里的保守估计，优先避免遗漏，可能留下少量重复。
- PNG 对文字最清晰；JPG 文件更小，但文字边缘会有轻微压缩痕迹。
- “页数上限”是安全阀；也可随时按 `F8` 停止。

## 使用限制

- 仅支持 Windows 10/11。
- EXE 是本机从源码直接构建的独立程序，没有商业代码签名；Windows 首次运行时可能显示 SmartScreen 提醒。不希望放行未签名 EXE 时，可按“从源码运行”启动同一份源码。
- 截图期间工具会把鼠标定位到所选区域中央，以便滚轮事件发给正确网页；结束后会恢复鼠标原位置。
- 如果目标浏览器以管理员身份运行，Windows 可能阻止普通权限程序向它发送输入；这种情况下本工具也需要以管理员身份运行。
- 工具不会绕过网站权限或 DRM，只保存屏幕上已经显示的像素。请确保截图与后续使用符合文档授权和网站规则。

## 从源码运行

本机建议使用 Python 3.12；构建依赖已锁定版本：

```powershell
py -3.12 -m pip install -r .\requirements.txt
py -3.12 .\src\main.py
```

也可以双击项目根目录的 `启动自动翻页截图工具.cmd`：它会优先打开已经打包好的 EXE；没有 EXE 时才尝试从源码启动。

## 测试与重新打包

```powershell
python -m unittest discover -s .\tests -v
python .\tests\desktop_smoke.py
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

`desktop_smoke.py` 会创建一个独立的滚动测试窗口，走真实 Windows 截屏与滚轮输入路径，并只关闭它自己创建的窗口。`build.ps1` 使用项目内的 `.venv-build` 构建环境，把独立可执行文件写到 `output\AutoPageCapture.exe`。
